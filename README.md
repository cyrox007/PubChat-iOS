# PubChat iOS

Нативный клиент PubChat на SwiftUI. Разработка ведётся параллельно с [Web/backend](https://github.com/cyrox007/PubChat) и [Android](https://github.com/cyrox007/PubChat-Android).

Первая задача — foundation, идентификация, безопасная сессия и CI-компиляция без локального Mac. До проверки CI и реальных устройств функциональный паритет и готовность к публикации не заявлены.
